# Instrukcja Symulatora Skrzynek CS2

## Wymagania
Upewnij się, że masz zainstalowany kompilator C++ (np. `g++`).

## Jak skompilować
Otwórz terminal w tym folderze i wpisz:

```powershell
g++ cs2_sim.cpp -o cs2_sim.exe
```

## Jak uruchomić
Po skompilowaniu uruchom program komendą:

```powershell
.\cs2_sim.exe
```
